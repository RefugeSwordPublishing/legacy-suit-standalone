# GuildWright trademark filing pack

For a use-based (Section 1(a)) application in International Class 42, owned by
**Refuge & Sword Publishing LLC** (Missouri). Hand this to an attorney or work from it directly in
Trademark Center at https://trademarkcenter.uspto.gov.

Written 2026-09-03. Not legal advice.

## The mark

**GUILDWRIGHT**, filed as a **standard character mark**. That protects the word itself in any font,
size, styling or colour, which is what actually matters. File the logo as a separate design mark
later if you want it; do not combine them in one application.

## Class 42, identification of goods and services

The USPTO charges $350 per class for an identification taken from the ID Manual and **$550 for
free-form wording**, so the entry below is built on the Manual's standard SaaS template. Paste it
into the Trademark Center picker and confirm it is recognised: the form shows which fee tier you
are on as you build the application. The Manual is searchable at https://idm-tmng.uspto.gov.

> Software as a service (SAAS) services featuring software for construction project management,
> namely, for preparing cost estimates and bids, generating invoices, tracking employee work hours,
> scheduling work crews, and recording job expenses.

That is roughly 240 characters, well inside the 1,000 character limit before the $200 surcharge.

**Why it is worded this way.** "Software as a service (SAAS) services featuring software for" is the
Manual's template for hosted software. "Namely" is what makes an identification definite; without
it, "construction project management" alone invites a refusal for indefiniteness. Every function
listed is something the product does today, which matters because a 1(a) filing swears to current
use and the specimen has to support it.

**Scope is a one-way door.** You can narrow an identification after filing but never broaden it, so
do not trim this to the minimum. Equally, do not pad it with things the product does not do.

Functions in actual use that could be added if you want more coverage, each of which then needs to
be supported: subcontractor bid requests, client approval and electronic signature of estimates,
change orders, and accounting synchronisation.

**Do not put in this application:** downloadable software (that is Class 9, see below) or business
management services (Class 35). Mixing classes in one identification draws an office action.

## Class 9, later, not now

Class 9 covers downloadable software. The Android app is not published, so claiming use-based rights
in Class 9 today would swear to use that has not happened. File Class 42 now and add Class 9 as a
separate application once the Play listing is live.

## Dates of first use

The form asks for two dates: first use **anywhere**, and first use **in commerce**. Both must be
truthful and provable. Evidence that exists today:

| Date | Evidence | Source |
|---|---|---|
| 2026-07-27 | First tenant account created (Legacy Renovations) | `companies.created_at` |
| **2026-08-07** | **Live Stripe products "GuildWright Field" and "GuildWright Pro" created, priced and sellable** | Stripe live account |
| 2026-08-07 | Timberline Renovations tenant created | `companies.created_at` |
| 2026-08-09 | CoreLine tenant created, an outside customer | `companies.created_at` |
| 2026-08-14 | Name first appears in the repository | git history |

The Stripe date is the strongest anchor: a third party's dated record showing priced, sellable
products under the name. The repository date is later than the rest only because the product was
renamed mid-flight, so treat it as a floor on nothing.

Before filing, check two things that may support an **earlier** date, since earlier is better as
long as it is provable: when guildwright.app first went live, and the earliest email or message in
which you offered the service to someone outside the company under this name. Note that Legacy
Renovations is your own affiliated company, so a first-use-in-commerce claim resting on it alone is
weaker than one resting on an unaffiliated customer.

## Specimen

For services, the specimen has to show the mark used in connection with **advertising or rendering
those services**, not just the logo on its own. A logo by itself is the single most common specimen
refusal.

Use a screenshot of guildwright.app showing the GuildWright name together with the description of
the software service, with the **URL and the capture date visible in the image**. A screenshot of
the signed-in app works too. Save it as PDF or JPG.

## Filing checklist

1. Verify your USPTO.gov account identity at
   https://www.uspto.gov/trademarks/apply/identity-verification, creating the account first at
   https://account.uspto.gov/profile/create-account. Start this before anything else: it is the
   slowest step and it is independent of the application.
2. Owner: Refuge & Sword Publishing LLC, with the LLC's address and state of formation.
3. Mark: GUILDWRIGHT, standard characters, no design.
4. Class 42 with the identification above.
5. Basis: Section 1(a), use in commerce, with both first-use dates.
6. Specimen as described.
7. Pay $350 and keep the serial number.

## After filing

Your name and address become public and you will receive official-looking mail and email demanding
payment for registration, monitoring or international listings. Nearly all of it is a scam. The
USPTO contacts you through your Trademark Center account and from uspto.gov addresses, and never
by post demanding a wire.

Use TM next to the name now. ® only after registration is granted, which typically takes eight to
fourteen months.
